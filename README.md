# jobpilot 🐋

> oi，小鬼。找工作很烦吧？
> 一百个字段、十八个网站、投完就忘了自己投过谁……
> 本鲸（不是肥鱼！）就是来收拾这些破事的。

住在你电脑里。网申、筛岗、记账，一条鲸全包。数据不出门。

## 本鲸能干什么

- 第一次只问 **12 个筛岗问题**；姓名、身份证这些，等真要填表了再问
- 帮你看岗位：推荐投 / 备选 / 不投，给你一句理由，不甩一堆清单
- 帮你填网申：先认页面，再列计划，**提交前把 diff 摊给你看**
- 投过谁、到哪一步，替你记着，下次不会重复投
- 没有浏览器也能干：给你一份逐字段填写稿，复制粘贴就行

## 30 秒抱回家

```bash
git clone https://github.com/gobulihx/jobpilot ~/.claude/skills/jobpilot
```

重开 Claude Code，然后说：

> 帮我弄求职助手

## 跟本鲸说话就行

不用背命令。你只管说人话：

| 你说 | 本鲸做 |
|---|---|
| 帮我建求职档案 | 分 4 轮问 12 个筛岗问题 |
| 今天有什么能投的 | 找岗、筛岗，给三档结论 |
| 这个岗位值不值得投 | 逐条对照硬门槛 |
| 投这个 | 认页面 → 列计划 → 给你看 diff → 你点头才填 |
| 有回音吗 | 扫邮箱，提议改状态 |
| 我还缺什么 | 把没填的列给你 |

命令是助手内部用的，你不用知道。**你负责说话，本鲸负责跑腿。**

## 本鲸的规矩

- 不替你点提交。填完页面留着，你自己看一眼、自己点。
- 不编经历。缺就是缺，宁可空着，也不给你瞎写。
- 不重复投。填之前先翻台账，投过的会提醒你。
- 不把你的资料传出去。没有遥测，没有上传，仓库里一个真人信息都没有。
- 正事不卖萌：身份证、钱、提交、出错，说清楚。

## 想让它自己填表？

装个浏览器工具就行，**强烈建议装**，装了本鲸自己会认：

```bash
python3 -m pip install playwright
python3 -m playwright install chromium
```

装完先连你开着的 Chrome（调试口 9222）；连不上就自己开一个专用浏览器，
第一次登录一次，之后记住。**填完不关页面**，留给你核对。

完整装法、验证、排错（含「装不上」「下载慢」「端口被占」）：
[browser-setup.md](references/browser-setup.md)

不装也能用，本鲸给你填写稿。不吓唬你。

## 找岗位用什么搜？

推荐 **exa**：能搜中文网页、能读正文。你要是已经在用 **DeepSeek 官方 API**，
用它自带的搜索也行。

没有也能干，就是范围小一点、慢一点：先看你给的链接，再翻官网，再看只读的招聘平台。
细节在 [search.md](references/search.md)。

## 数据在哪

只在本机 `~/.jobpilot/`：目录 700，值文件 600，日志脱敏，截图不往上传。

想删就删：

```bash
rm -rf ~/.jobpilot
```

详见 [PRIVACY.md](PRIVACY.md)。

## 本鲸不会的

- 不代注册、不代过验证码、不代实人认证
- 不代聊（BOSS / 智联只读）
- 不默认提交
- 只覆盖中国大陆校招站，国际 ATS 还没做
- 页面改版会让旧计划失效，得重新认一遍
- 网站特别怪的时候，可能只能给你填写稿

## 想帮忙？

最欢迎：**字段别名**、**脱敏的失败页面**、**通用规则的修正**。
公司专属的站点卡不用提交，放你自己 `~/.jobpilot/sites/` 就行。

见 [CONTRIBUTING.md](CONTRIBUTING.md)。
