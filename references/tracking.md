# 台账

## 状态机

```
草稿 → 已填未投 → 已投递 → 筛选中 → 笔试 → 面试 → 录用
                                          ↘ 已结束
```

- 状态由事件推导，`applications.status` 只是缓存。
- 事件表保留每一次变化，能算停留时长和漏斗。
- 非法状态直接拒绝，不做「自动纠正」。

## 幂等

唯一键 = 公司 + 岗位 + 城市 + 批次，先归一化（去空格、标点、大小写）。

同一家公司同名岗位在不同批次算两条；同批次重复投只算一条。

## 字段

| 字段 | 说明 |
|---|---|
| 公司 / 岗位 / 城市 / 批次 | 唯一键 |
| 状态 | 八档之一 |
| 来源 | 官网 / 内推 / 招聘会 |
| 投递时间 | 第一次进入已投递的时间 |
| 简历版本 | 用的哪一版 |
| 回执号 | 站点给的编号 |
| 链接 | 原始入口 |

## 导出

- `ledger export` 默认写 csv（UTF-8 BOM，Excel 直接打开不乱码）。
- 装了 openpyxl 会同时写 xlsx。
- 导出文件在 `~/.jobpilot/exports/`，不进仓库。

## 回执

- 只读本地邮件文件，按 `Message-ID` 去重。
- 关键词分类：笔试 / 面试 / 录用 / 已结束。
- 只有能对上台账里的公司才提议改状态；对不上标问号。
- 用户确认后才写事件。
